What is a Computer?

A computer receives, processes, stores, and produces information.

Definition: A computer is an electronic device that receives data, processes it according to a set of instructions, stores it, and produces useful information.

Main characteristics

  • Speed: performs millions of operations per second.
  • Accuracy: produces reliable results.
  • Storage: can store large amounts of data.
  • Versatility: can perform different tasks such as calculations, text processing, and images.
  • Programmability: follows a set of instructions (a program).
InputData entered (keyboard, mouse, scanner)
ProcessingCPU executes instructions
OutputInformation (screen, printer, speakers)
StorageData and programs saved for later

What is Computer Science?

The scientific discipline concerned with processing information using computers.

Computer Science studies the principles, methods, and tools for processing information using computers.

Main aspects

Information representation

How to represent numbers, text, images, and other data.

Algorithms

Methods used to solve problems.

Programming

Writing instructions for a computer.

Data structures

Organizing and storing data efficiently.

Software development

Designing and building computer programs.

Applications

Using computers to solve real-world problems in different domains.

Examples of application areas shown in the course include healthcare, banking and finance, transport, e-commerce, and environmental science.

Main Components of a Computer

Hardware components work together to perform input, processing, storage, and output.

1. Input devices

Allow the user to enter data and instructions. Examples: keyboard, mouse, scanner, microphone.

2. Central Processing Unit (CPU)

Executes instructions and processes data. The course identifies the Control Unit and Arithmetic Logic Unit (ALU) as its two main parts.

3. Memory and storage

RAM is temporary storage for data and programs in use. Secondary storage (HDD, SSD, USB) is used for long-term storage.

4. Output devices

Display results produced by the computer. Examples: screen, printer, speakers, projector.

Information Processing Cycle

A computer transforms data into useful information through four main stages.

1. InputRaw data enters the computer.
2. ProcessingThe CPU executes instructions on the data.
3. OutputUseful results are produced.
4. StorageData and programs are saved for later use.

The cycle repeats as needed. Examples of input include a keyboard, mouse, or scanner; outputs may include text, images, or reports.

Problem Solving

A problem is a situation or question that needs to be solved.

Examples of problems

  • Calculate the average of a set of numbers.
  • Find the largest value in a list.
  • Determine whether a number is positive or negative.
  • Search for a specific element.
  • Manage student records.

How a problem is characterized

  • Inputs: the given data.
  • Outputs: the expected results.
  • Conditions (constraints): rules to be respected.
  • Goal: a clear result to be achieved.

Problem-solving steps

  1. Understand the problem: identify inputs, outputs, and constraints.
  2. Design a solution (algorithm).
  3. Implement the solution (program).
  4. Test and verify the solution.
  5. Refine and improve if necessary.

What is an Algorithm?

A finite sequence of well-defined steps for solving a problem or performing a task.

Algorithm: a finite sequence of well-defined steps to solve a problem or perform a task.

Characteristics of an algorithm

  • Well-defined: steps are clear and unambiguous.
  • Finite: it must terminate.
  • Input: it has zero or more inputs.
  • Output: it produces one or more outputs.
  • Effective: each step can be executed in finite time.
  • General: it can apply to similar problems.

Example: sum of two numbers

Problem: read two numbers and calculate their sum.

  1. Start.
  2. Read the first number a.
  3. Read the second number b.
  4. Compute s = a + b.
  5. Display s.
  6. End.
Algorithm Sum_Two_Numbers Input: a, b Output: s Begin Read(a) Read(b) s ← a + b Print(s) End

Representing Algorithms

The PDF presents three ways to describe an algorithm.

1. Natural language

Describe the steps using simple, clear sentences in human language.

2. Pseudocode

A structured, informal representation of an algorithm, similar to a programming language but not tied to a specific language.

3. Flowchart

A graphical representation of an algorithm using standard symbols.

Example: average of three numbers

Read a, b, c; calculate s = a + b + c; calculate avg = s / 3; display avg.

Algorithm Average_Three_Numbers Var: a, b, c, s, avg : real Begin Read(a) Read(b) Read(c) s ← a + b + c avg ← s / 3 Print(avg) End

From an Algorithm to a Program

An algorithm describes a solution independently of a programming language. To execute it on a computer, it must be translated into a programming language.

Development steps

1. AnalyseUnderstand the problem.
2. DesignWrite an algorithm or flowchart.
3. TranslateUse a programming language, such as C.
4. Compile and runBuild and execute the program.
5. TestValidate the result.

Example: average of three numbers in C

#include <stdio.h> int main() { float a, b, c, avg; printf("Enter three numbers: "); scanf("%f %f %f", &a, &b, &c); avg = (a + b + c) / 3; printf("Average = %.2f\\n", avg); return 0; }

Key point: pseudocode and flowcharts help design and understand the solution; a program is its executable implementation.

Worked Example: Maximum of Three Numbers

Read three numbers and determine the largest one.

Input

Three numbers: a, b, c.

Output

The maximum value among a, b, and c.

Read(a) Read(b) Read(c) max ← a if (b > max) then max ← b end if if (c > max) then max ← c end if Print(max)

Trace example from the course

Input: a = 12, b = 25, c = 7. Start with max = 12. Since 25 is greater than 12, set max = 25. Since 7 is not greater than 25, keep max unchanged. The output is 25.

What is a Programming Language?

A formal language used to write programs that can be executed by a computer.

A programming language is a set of rules (syntax and semantics) that allows a programmer to write instructions to solve a problem and control a computer.

Purpose

  • Express algorithms in a form understandable by a computer.
  • Write, test, and modify programs.
  • Communicate with the computer and use its resources.
  • Develop software applications.

Main elements

Syntax

The structure and form of valid instructions.

Semantics

The meaning of the instructions.

Vocabulary

Keywords, operators, identifiers, and other language elements.

Examples shown in the PDF include C, C++, Python, Java, C#, JavaScript, and PHP. The same instruction can have different syntax in different languages.

Types of Programming Languages

The course classifies languages by level of abstraction and how they are translated and executed.

1. Machine language

Written in binary code (0 and 1); directly understood by the CPU; difficult to write, read, and maintain; very fast execution.

2. Assembly language

Uses mnemonic codes such as MOV, ADD, and SUB; closer to hardware; translated into machine code using an assembler.

3. High-level languages

Use syntax closer to natural language; easier to write, read, and maintain; generally more portable; translated using a compiler or interpreter.

Translation hierarchy

High-level languagee.g., C
Compiler / interpreterTranslation tool
Assembly languageMnemonic code
AssemblerTranslation tool
Machine languageBinary code

What is C Language?

C is a high-level programming language used for general-purpose programming, systems development, and education.

The PDF describes C as a general-purpose, procedural programming language developed in the 1970s by Dennis Ritchie at Bell Labs (USA).

Main characteristics and advantages

  • High-level language: easier to write and understand than machine or assembly language.
  • General-purpose and procedural: programs are organized into functions and procedures.
  • Efficient and fast, with access to low-level operations such as memory management.
  • Portable across different operating systems with few modifications.
  • Simple syntax, many operators and data types, and a large number of libraries.

Example of a C instruction

#include <stdio.h> int main() { printf("Hello, this is a C program!\\n"); return 0; }

This instruction is written in C, displays a message on the screen, and can be compiled and executed.

What is a Compiler?

A compiler translates source code written in a high-level programming language into machine code.

Role of the compiler

  • Translates source code (e.g., C) into machine code.
  • Detects and reports syntax errors.
  • Can optimize code to improve performance.
  • Generates an executable file, such as an .exe file.

Compilation process

Source codeC program
CompilerTranslation
Executable programMachine code
According to the course slide, the compiler translates the program before execution. If errors are found, compilation stops; the generated executable is machine-dependent.

What is a Development Environment?

An Integrated Development Environment (IDE) helps write, compile, run, and debug programs.

Main functions

  • Create and edit source files, such as .c files.
  • Compile the program.
  • Run the executable program.
  • Display error messages.
  • Help debug and fix errors.
  • Provide tools such as syntax highlighting, auto-completion, and project management.

Examples for C shown in the PDF

Code::Blocks, Dev-C++, Visual Studio Code, and CLion.

Typical workflow

  1. Write the code in the editor.
  2. Compile or build the program.
  3. Run the program.
  4. View the result and debug if necessary.

The PDF notes that a development environment is a tool, not a programming language, and that a compiler is often integrated into an IDE.
